## What is Astro?

[Astro](https://astro.build/) is a modern static site generator that allows you to build fast.

content-focused websites using your favorite JavaScript framework. It is designed to be simple and flexible, making it easy to create beautiful and performant sites with minimal effort.

## Features of Astro

Astro offers a range of features that make it a powerful tool for building websites:

- **Static Site Generation**: *Astro* generates static `HTML` files at build time, ensuring fast load times and improved SEO.
- **Framework Agnostic**: You can use Astro with any JavaScript framework, including React, Vue, and Svelte.
- **Partial Hydration**: Astro only hydrates the components that need interactivity, reducing the amount of JavaScript sent to the browser.
- **Markdown Support**: Write your content in Markdown and let Astro handle the rendering.

## Code Example

```astro title="counter.astro" {3}
---
interface Props {
  count: number
}

const { count } = Astro.props
---

<div>
  <h1>Count: {count}</h1>
  <button onClick={() => count++}>Increment</button>
</div>
```
