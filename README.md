# 星星的筆記．Lucas

![星星的筆記．Lucas](screenshot.png)

</div>

部落格 [星星的筆記．Lucas](https://star-note-lucas.me/) 的原始碼。

技術棧使用 [Astro](https://astro.build/)、[Tailwind CSS](https://tailwindcss.com/)、[Vue.js](https://vuejs.org/)。部署在 [Vercel](https://vercel.com/) 平台。

## 功能

- Markdown 文章
- 文章分類
- 文章標籤

## 開發

```bash
yarn
yarn dev
```
